# ToDo App

A dark-themed todo list built with React, Vite and Tailwind CSS. Tasks are saved in your browser's local storage, so they stay put after a refresh.

**Live site:** https://alemieux3.github.io/todo-app/

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Deploy

Every push to `main` builds the app and publishes it to GitHub Pages through `.github/workflows/deploy.yml`.
